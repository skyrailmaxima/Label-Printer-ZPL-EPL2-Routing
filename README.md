# Label-Printer-ZPL-EPL2-Routing

Routes `.zpl` / `.epl` / `.epl2` label files to a printer of your choosing on
locked-down corporate Windows 11 machines, where the old
`net use LPT2: \\%ComputerName%\PrinterShare` trick no longer works.

Double-click a label file and it prints. A separate batch tool prints every
label file in a folder. No admin rights required.

## The problem this solves

The classic way to feed raw ZPL/EPL to a label printer was to share the
printer locally and route a port to it:

```bat
net use LPT2: \\%ComputerName%\LD620D
copy /b label.zpl LPT2:
```

On a corporate-managed Windows 11 machine this often breaks, because:

- Win11 disables insecure SMB guest logons by default, and GPO enforces it,
  so the loopback `net use` to your own machine's share is rejected.
- Group Policy frequently strips local printer shares or disables
  file/print sharing on the domain profile.
- PrintNightmare (CVE-2021-34527) mitigations and Point-and-Print
  restrictions block the self-share workflow.

Instead of fighting SMB, this project sends the file straight to the Windows
print spooler using the **RAW** datatype. RAW bypasses driver processing
entirely — the same end result the old `copy /b` chain produced — but it's a
purely local operation, so none of the SMB/share lockdowns apply.

## Is this for you?

Use this if **all** of the following are true:

- You have an older label printer (Zebra, OKI, TSC, Godex, Honeywell,
  etc.) that takes raw ZPL or EPL/EPL2.
- You're on Windows 10 or 11, and an old `net use` / port-routing setup
  stopped working — typically after a move to a corporate-managed machine.
- The printer still shows up in Windows (Settings > Printers, or
  `Get-Printer` in PowerShell). This tool routes to an installed printer;
  it does not install or fix the driver itself.

It will **not** help if the printer isn't enumerable to your user account
at all (a harder GPO/spooler lockdown - that's an IT conversation), or if
your software needs an actual `LPT2:`/COM port handle rather than a print
job.

## Requirements

- Windows 10 or 11
- Python 3.8+ (3.10+ recommended)
- [`pywin32`](https://pypi.org/project/pywin32/)

```
pip install pywin32
```

## Install

1. Download or clone this repo so all `.py` files sit in one folder.
2. From that folder, run:

   ```
   python install.py
   ```

3. The installer will:
   - copy the tool files to `%LOCALAPPDATA%\zpl-tools` (or a path you choose),
   - list every printer Windows can see and let you pick one,
   - save your choice to `config.json`,
   - register `.zpl` / `.epl` / `.epl2` so double-clicking prints,
   - optionally drop a desktop shortcut for the batch tool.

Re-run `install.py` any time to switch printers or repair the
association — it's idempotent and pre-selects your current printer.

## Usage

**Single file** — double-click any `.zpl`, `.epl`, or `.epl2` file. It
prints silently to your configured printer; a message box appears only on
failure.

**Batch** — launch the batch GUI:

```
pythonw "%LOCALAPPDATA%\zpl-tools\zpl_batch.py"
```

(or use the desktop shortcut). Pick a folder and printer, optionally
recurse into subfolders and edit the extension filter, then **Print All**.
A live log shows OK/FAIL per file.

## What's in the repo

| File           | Purpose                                                        |
| -------------- | -------------------------------------------------------------- |
| `install.py`   | One-time setup: copies files, picks printer, registers types.  |
| `zpl_core.py`  | Shared core: printer discovery, config, RAW spooler I/O.        |
| `zpl_print.py` | Double-click worker invoked by the file association.           |
| `zpl_batch.py` | Tkinter GUI to print every label file in a folder.             |
| `config.json`  | Generated by the installer; holds the selected printer name.   |

## Troubleshooting

**Double-clicking opens the wrong app / does nothing.** Windows may have a
`UserChoice` override for the extension. Right-click a `.zpl` file >
*Open with* > *Choose another app* > *Browse* to `pythonw.exe` > check
*Always use this app*. The registered association takes over after that.

**"No printer configured" / wrong printer.** Re-run `install.py` and pick
again, or edit the `printer` value in `config.json` in the install folder.

**Printer not in the list.** Confirm it appears in
`Get-Printer | Select Name` (PowerShell). If it doesn't show there, the
spooler/GPO lockdown is upstream of this tool — raise it with IT.

**Prints blank or garbage.** The file must contain raw printer commands
(ZPL starting with `^XA`, EPL with `N`/`q`/`Q` etc.) matching your
printer's language, not a rendered image or PDF.

**Desktop shortcut step failed.** Harmless — printing still works. Usually
an OneDrive Known Folder Move quirk; current versions resolve the real
Desktop path and skip the shortcut gracefully if they can't.

## Security & privacy

Everything is local and per-user: registry writes go to `HKCU` only, files
are copied under your own `%LOCALAPPDATA%`, and label data goes straight to
the local spooler. No network calls, no admin elevation, no services
installed.
